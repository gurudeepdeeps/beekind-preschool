# BeeKind Preschool Website

A modern, responsive, and aesthetically pleasing website for **BeeKind Preschool**, a nurturing educational environment dedicated to early childhood excellence. Located in Kunigal, Karnataka, BeeKind Preschool focuses on play-based learning, holistic growth, and providing a joyful start to a child's academic journey.

## 🌟 Features

-   **Premium Design**: Vibrant and playful aesthetics using curated color palettes (Yellow, Red, White) and modern typography.
-   **Fully Responsive**: Optimized for desktops, tablets, and mobile devices.
-   **Interactive UI**:
    -   Smooth scroll animations using **AOS (Animate on Scroll)**.
    -   Dynamic hero sliders with **Slick Carousel**.
    -   Interactive counters for school achievements.
    -   Integrated Image and Video galleries.
-   **Localized Performance**: All fonts (Google Fonts, Font Awesome) and assets are hosted locally to ensure fast load times and zero external dependencies.
-   **SEO Optimized**: Comprehensive meta tags, Twitter cards, and Schema.org JSON-LD markup for local business visibility.
-   **Functional Components**:
    -   Quick Enquiry modal and contact forms.
    -   Direct call and WhatsApp integration.
    -   Interactive Google Maps integration.

## 🚀 Getting Started

### Prerequisites

You only need a modern web browser and a local web server to run the project.

### Running Locally

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/gurudeepdeeps/beekind-preschool.git
    cd beekind-preschool
    ```

2.  **Serve the files**:
    You can use any local server. If you have Node.js installed, `serve` is a great option:
    ```bash
    npx serve
    ```
    Alternatively, use the "Live Server" extension in VS Code.

3.  **View the site**:
    Open your browser and navigate to `http://localhost:3000` (or the port provided by your server).
